## 2026-11-09 · fix(packs): skip live-write workflow gates for L1 read tool calls
- **Kind:** code
- **Task:** T-0022
- **Bug:** BUG-0081
- **Why:** SPEC §4.12.3 L1 blocks a write when the phase or plan does not allow it, never a read; the L1 hook scope carried Read targets in proposedPaths with no tool kind, so markerRealGuard judged every Read as a live write and core/workflow-gates plus core/writes-within-plan denied any src read in a planning task, leaving an agent unable to read the code it is planning against
- **What went wrong:** the firing meta-guard showed the symptom as pre-emption (read probes answered by workflow-gates instead of the rule under test), which hid that the deny itself was the user-facing defect

- **Lessons:** L1 scope judges must know the access kind of the call; a guard that reuses proposedPaths should state whether it judges reads, writes or both
